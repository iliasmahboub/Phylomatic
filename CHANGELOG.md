# Changelog

All notable changes to Phylomatic are documented here.

## 0.1.0 - 2026-04-09

- Added the Sanger chromatogram to phylogenetic tree workflow.
- Added FastAPI endpoints and WebSocket progress updates.
- Added a React/Vite frontend with upload, BLAST result, tree, sequence, and
  export views.
- Added mocked unit tests for assembly, BLAST parsing, Entrez, alignment, QC,
  confidence scoring, tree construction, and SVG rendering.
- Added optional FastTree support with Neighbor-Joining fallback.
- Added JOSS paper draft and bibliography.
