# Support

Use GitHub Issues for bug reports, installation problems, and reproducible
workflow failures:

https://github.com/iliasmahboub/Phylomatic/issues

For each issue, include:

- Operating system and Python/Node versions
- The command that failed
- Full error output
- Whether the failure happened in installation, upload, BLAST, Entrez,
  alignment, tree construction, visualization, or export
- A minimal input file or synthetic reproducer when possible

Do not upload private clinical, student, or unpublished sequence data to public
issues. Share a synthetic reproducer instead.
